# Brechó da Giovanna

Controle simples para um brechó, feito em um único arquivo HTML. Para usar,
basta abrir o arquivo no navegador: não precisa instalar nada e não precisa
de internet.

## O que ele resolve
No brechó cada peça é única — não existe "20 camisetas M", existe *aquela*
camiseta. Controlando em caderno, a dona não sabe quantas peças tem na loja,
nem quanto dinheiro está parado em estoque, e os clientes não ficam
registrados em lugar nenhum.

## As três telas
- **Produtos** — cadastra a peça (nome, categoria, tamanho e preço). Cada peça
  aparece na vitrine como uma etiqueta de roupa.
- **Clientes** — cadastra nome, telefone e cidade de quem compra.
- **Visão geral** — o resumo: quantas peças, quantos clientes e o valor total
  do estoque.

## O que ficou de fora
Registro de venda, controle de caixa e nota fiscal. Quando a peça sai da loja,
ela é removida manualmente.

## Observação
Os dados ficam salvos na memória do navegador, naquele computador. Fechar o
navegador não apaga nada, mas os cadastros não aparecem em outro computador.

## Feito com
HTML, CSS e JavaScript. O código está todo comentado em linguagem simples,
para quem não programa conseguir acompanhar.
